# GBA Online

Trình giả lập Game Boy Advance chạy trên trình duyệt (EmulatorJS + mGBA).

- Thư viện ROM, lưu nhanh 5 slot, auto-save, tua nhanh/chậm/ngược
- Cheat, patch IPS/UPS/BPS, xuất/nhập .sav và state
- Đồng bộ ROM và save với thư mục Google Drive (Chrome/Edge máy tính)

ROM không được kèm trong repo và không bị upload, chỉ chạy trên máy bạn.
